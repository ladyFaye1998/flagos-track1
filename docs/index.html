What's in the box

Three tiers, one op per file, PyTorch reference and Triton kernel side by side. Backward kernels for the five ops that real training pipelines differentiate.

Easy 8 element-wise

abs, exp, log, sigmoid, relu, tanh, gelu (exact + tanh), silu.

  • fp32 internal compute, dtype-preserving output
  • Autotuned BLOCK_SIZE ∈ {1024, 2048, 4096}
  • Geomean parity to 1.76× vs eager (bandwidth-bound)

Medium 8 classical

softmax, layer_norm, rms_norm, cross_entropy, embedding, dropout, argmax, matmul.

  • Single-pass fused reductions, fp32 accumulators
  • matmul wrapper auto-dispatches Triton ↔ vendor BLAS per shape
  • Geomean wins: rms_norm 7.5×, embedding 4.3×

Hard 4 advanced

flash_attention (FA-v2 forward, causal), rope, fused_moe_topk, rms_norm_backward.

  • Per-arch tile schedule on flash_attention
  • fp32 router GEMM in fused_moe_topk for precision
  • Geomean wins: flash 10.6×, rope 5.2×

One example kernel

The fused single-pass rms_norm forward. Mean of squares in fp32, rsqrt, scale, store — all in one launch. 

@triton.jit
def _rms_norm_kernel(
    x_ptr, w_ptr, y_ptr,
    n_cols, eps,
    stride_xr, stride_yr,
    BLOCK_N: tl.constexpr,
):
    row = tl.program_id(0)
    col_offs = tl.arange(0, BLOCK_N)
    mask = col_offs < n_cols

    x = tl.load(x_ptr + row * stride_xr + col_offs, mask=mask, other=0.0).to(tl.float32)
    w = tl.load(w_ptr + col_offs,                   mask=mask, other=1.0).to(tl.float32)

    # single-pass mean of squares -> rstd -> normalize -> scale
    var  = tl.sum(x * x, axis=0) / n_cols
    rstd = 1.0 / tl.sqrt(var + eps)
    y    = x * rstd * w

    tl.store(y_ptr + row * stride_yr + col_offs, y.to(y_ptr.dtype.element_ty), mask=mask)

Cross-platform

device_caps.detect() returns the vendor + arch at import time. Kernels with per-vendor tile schedules (matmul, flash_attention) read from it and pick the right config. Full matrix in BACKENDS.md.

NVIDIA Ampere (sm_80 / 86 / 87)

Tested by author on RTX 3060 Laptop GPU · per-vendor configs for matmul + flash_attention

NVIDIA Hopper (sm_90)

Larger 128×256×64 tiles, 3-stage pipeline · selected from arch == "hopper"

NVIDIA Ada (sm_89) · Turing (sm_75)

Uses the Ampere config path

AMD CDNA2 / CDNA3 (MI200, MI300)

Smaller K tiles, 2-stage pipeline · selected from vendor == "amd"

Intel Xe-HPC / Xe-HPG

Default config set via Triton's standard backend

CPU (no CUDA, no Triton)

PyTorch eager fallback · 21 parity cases run in GitHub Actions on every push
